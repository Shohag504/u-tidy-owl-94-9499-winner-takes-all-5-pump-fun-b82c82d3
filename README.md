A deterministic pump.fun replay trading bot for the "Winner Takes All — $5 Pump.fun Replay Sprint". It rides confirmed early breakouts — coins 2–10 slots old with at least 20 distinct buyers and positive recent net flow — banks part of the move quickly behind a trailing stop, and never holds a faded coin: hard stop, creator-sell and big-seller exits, and a hold cap. Small 0.01 SOL "scout" trades on a weaker version of the same filter keep the guardrail pace (25 coins with round trips, comfortably over the 20-coin bar) without burning fees on instant sells: scouts exit on a +25% take-profit, a trailing stop, a small stop, or a hold cap.

## Run it

```sh
node main.ts
```
